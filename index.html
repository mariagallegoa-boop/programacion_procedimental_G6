MENU

El módulo de menú permite visualizar de forma clara y organizada todos los productos que ofrece el restaurante, incluyendo descripciones, precios e imágenes.

INVENTARIO

El módulo de inventario permite gestionar y controlar los insumos y productos del restaurante en tiempo real. Facilita el registro de entradas y salidas, evitando faltantes o excesos de stock.

USUARIOS

El módulo de usuarios permite gestionar las cuentas de acceso al sistema, asignando roles y permisos según las funciones de cada persona. Facilita la administración segura de la información y el control de quién puede realizar determinadas acciones.

PEDIDOS
